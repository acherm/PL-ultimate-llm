吾有一術。名之曰「篩」。欲行是術。必先得一數。曰「甲」。乃行是術曰。
    吾有一列。名之曰「乙」。
    吾有一數。曰「丙」。恆為二。
    為是「丙」遍。凡「丙」之於「甲」者。
        加一於「丙」。
        吾有一爻。名之曰「丁」。恆為陽。
        吾有一數。曰「戊」。恆為二。
        為是「戊」遍。凡「戊」之於「丙」者。
            若「丙」除「戊」之餘為零者。
                吾有一爻。曰「丁」。變為陰。
                乃止。
            加一於「戊」。
        若「丁」者。
            加「丙」於「乙」。
    厥後。書之。
是謂「篩」之術也。

批曰。「「篩」一百。書素數。」。
施「篩」於一百。
