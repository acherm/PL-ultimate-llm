Parallel Fibonacci (Cilk spawn/sync)

Origin · Download · manifest.json
code.cilk · license: CC BY-SA 4.0 · added: 2026-02-05T21:07:49Z
cilk int fib (int n) {
  if (n < 2) return n;
  int x = spawn fib(n-1);
  int y = fib(n-2);
  sync;
  return x+y;
}
