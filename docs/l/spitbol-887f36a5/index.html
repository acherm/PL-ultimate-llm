Fibonacci Sequence Generator

Origin · Download · manifest.json
code.spt · added: 2026-02-06T10:30:00Z
* Fibonacci sequence generator in SPITBOL
* Computes and prints the first N Fibonacci numbers

        OUTPUT = "Enter number of Fibonacci numbers to generate:"
        N = INPUT
        N = GT(N,0) N                           :F(ERROR)
        
* Initialize first two Fibonacci numbers
        F1 = 0
        F2 = 1
        OUTPUT = "Fibonacci sequence:"
        OUTPUT = F1
        LE(N,1)                                 :S(END)
        OUTPUT = F2
        LE(N,2)                                 :S(END)
        
* Generate remaining Fibonacci numbers
        I = 2
LOOP    I = LT(I,N) I + 1                       :F(END)
        NEXT = F1 + F2
        OUTPUT = NEXT
        F1 = F2
        F2 = NEXT                               :(LOOP)
        
ERROR   OUTPUT = "Error: Please enter a positive integer"
END
