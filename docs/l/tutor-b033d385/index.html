Drawing a Circle in PLATO TUTOR

Origin · Download · manifest.json
code.tut · added: 2025-11-02T17:16:22Z
* To draw a circle on the PLATO screen
* using the line command.
*
* By doing this, we can specify the color
* of the circle.

        define  x=v1,y=v2,deg=v3,x1=v4,y1=v5
        define  xc=100,yc=100,radius=50

        calc    deg=>0
loop    line    xc+radius*cos(deg),yc+radius*sin(deg),-
                xc+radius*cos(deg+1),yc+radius*sin(deg)
        calc    deg+1=>deg
        j       deg<360,loop
