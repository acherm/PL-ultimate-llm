Fibonacci Sequence Generator

IDENTIFICATION DIVISION.
PROGRAM-ID. FIBONACCI.
DATA DIVISION.
WORKING-STORAGE SECTION.
01  N           PIC 99 VALUE 10.
01  FIB-PREV    PIC 9(8) VALUE 0.
01  FIB-CURR    PIC 9(8) VALUE 1.
01  FIB-NEXT    PIC 9(8).
01  I           PIC 99.

PROCEDURE DIVISION.
    DISPLAY "Fibonacci sequence:".
    DISPLAY FIB-PREV.
    DISPLAY FIB-CURR.

    PERFORM VARYING I FROM 3 BY 1 UNTIL I > N
        COMPUTE FIB-NEXT = FIB-PREV + FIB-CURR
        DISPLAY FIB-NEXT
        MOVE FIB-CURR TO FIB-PREV
        MOVE FIB-NEXT TO FIB-CURR
    END-PERFORM.

    STOP RUN.
