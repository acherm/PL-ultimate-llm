== Simple TACL program - Variable demonstration
== This demonstrates basic TACL variable operations

#PUSH name
#SET name John
#OUTPUT Name: [name]

#PUSH counter
#SET counter 0
[#LOOP |WHILE| counter < 5|DO|
  #OUTPUT Counter value: [counter]
  #SET counter [#COMPUTE counter + 1]
]

#OUTPUT Final counter: [counter]
#POP counter
#POP name
