* COMIT Pattern Matching Example
* Find and replace patterns in text
START   READ    $1
        TEST    $1 = 'HELLO *'
        GO      FOUND
        GO      NOTFND
FOUND   REPLACE $1 WITH 'GOODBYE' + '*'
        PRINT   $1
        STOP
NOTFND  PRINT   'NO MATCH'
        STOP
